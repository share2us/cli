Share2Us apt repository

Debian and Ubuntu packages for the s2u command line. Signed with the key at /share2us-apt.gpg (ASCII).

curl -fsSL https://apt.share2.us/share2us-apt.gpg | sudo tee /usr/share/keyrings/share2us-apt.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/share2us-apt.gpg] https://apt.share2.us stable main" | sudo tee /etc/apt/sources.list.d/share2us.list
sudo apt update && sudo apt install s2u

Pre-release builds live in the beta suite: use beta main instead of stable main. The repository is published by the share2us/cli release workflow; releases and checksums are on GitHub Releases.
